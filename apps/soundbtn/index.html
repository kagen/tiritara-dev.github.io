音ボタン SoundBtn

エンタメ · Android / iOS

降車ボタン・風鈴・蝉・タイマーをワンタップで

Android 版をGoogle PlayiPhone・iPad 版をApp Store

押すと、音が鳴る。それだけ。

「音ボタン」は、おなじみの効果音を大きなイラストボタンで鳴らせる、
シンプルなサウンドアプリです。
ホーム画面のウィジェットからも、アプリを開かずにワンタップで再生できます。

収録している音

  • バスの降車ボタン … 「とまります」のほか、「こまります」「つまります」「たまります」も収録
  • 卓上ベル … チーーーン
  • トイレの音消し … 気になる音をやさしくマスキング
  • ダンス風の掛け声
  • カンフー風の掛け声
  • おなら … 十数種類をランダム再生。犯人はあなたではありません
  • 夏の風物詩 … 風鈴、セミの鳴き声
  • カウントダウン爆弾 … 3、2、1、ドカン（コミカルな演出です）
  • キッチンタイマー … マンガ風のカウントダウン付き

主な機能

  • 大きなイラストをタップして、すぐに音を再生
  • 音ごとに複数のパターンからランダム再生
  • 再生中にもう一度タップすると、すぐに停止
  • 音の再生中は、押された状態のイラストを表示
  • 左右のボタンやスワイプ操作で音を切り替え
  • ボタンを長押しして下へドラッグし、ホーム画面へウィジェットを配置
  • ウィジェットから、アプリを開かずに再生・停止
  • 買い切りオプションで広告を削除

こんなときに

降車ボタンを押してみたいとき、卓上ベルを鳴らしたいとき、
トイレで音消しを使いたいとき、カップ麺を待つとき。
会話のオチにも、日常のちょっとした合図にも。

音量は端末のメディア音量で調整できます。
本アプリには広告が表示されます。アプリ内購入の買い切りオプションで広告を削除できます。

※ 音が鳴ると困る場所ではご注意ください。とくに、おなら。
